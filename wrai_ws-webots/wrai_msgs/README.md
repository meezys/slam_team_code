# wrai_msgs
A collection of ROS messages and services used by the team

## Messages:
| Name | Description |
| ---- | ---- |
| ConeArray.msg | A message containing lists of 2D locations of blue, yellow, orange and big cones |
| Midpoints.msg | A list of 2D points that states the path the car should travel along |
| ConeMeasurement.msg | A relative measurement of a single cone |
| ConeMeasurementArray.msg | An array of measured relative cone positions (`ConeMeasurement`) from a sensor |
